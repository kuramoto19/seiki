# 学びの多様化学校の教育理念・教育目標 一覧

調査日: 2026-10-13。[schools.md](schools.md) の学校について、教育理念・教育目標を Web 検索で調べた結果です。学校や設置者が明示していない場合は、Web ページの情報（校名の由来、特色、設置のねらい、教育課程など）から理念・目標を読み取って記入し、印を付けています。

## 印の意味

| 印 | 意味 |
|---|---|
| （印なし） | **明示**: 学校・設置者が「教育理念」「教育目標」「建学の精神」「校訓」「スクールビジョン」「コンセプト」「めざす学校像」「基本理念」などとして掲げている文言 |
| **△** | **一部明示**: 一部は明示されている（学校全体・法人の理念、目的、キーワードなど）。学びの多様化学校（コース・分教室）としての部分は Web 情報から推定 |
| **※** | **推定**: 明示された理念・目標が見つからず、Web ページの情報から読み取ってまとめたもの |

## 読むときの注意

- 調査環境から学校や自治体のサイトを直接開けないため、**検索エンジンの要約をもとにしています**。「」で囲んだ文言も、原文と細部が違う可能性があります。引用するときは出典で原文を確認してください。
- **※ と △ の推定部分は、私（Claude）が Web 情報から読み取ってまとめた文章**で、学校の公式の文言ではありません。
- 「根拠」の列に、推定のもとにした情報を書いています。

## 1. 全体に共通する考え方

|---|---|---|

- **公立校**は「社会的自立」「居場所」「つながり」という、国の制度の考え方に近い言葉が多くなっています。
- **私立校**は学校法人の建学の精神をそのまま土台にしています（星槎「共生」、生野学園「自然出立」、東京シューレ「子ども中心」、静岡学園「孝友三心」など）。
- 明示された理念・目標がない学校でも、**校名・愛称の由来**（ねいろ、はしうち、UMI、琴葉、草潤、窓明、もくせい、プリズム、樸、悠志 など）に考え方がはっきり表れています。
