## 1. 制度の概要

- **正式な位置づけ**: 学校教育法施行規則 第56条（小学校）、第79条（中学校で準用）、第86条（高等学校）などにもとづき、**文部科学大臣が指定する学校**です。不登校の児童生徒の実態に合わせて、**教育課程の基準によらない特別の教育課程**を編成できます。
- **名称の変遷**: 2004年度に始まった「不登校特例校」の通称が、**2023年8月31日に「学びの多様化学校」へ改められました**。新しい名称は、学校の児童生徒や教職員の意見をもとに決まりました。
- **主な特徴**（各校でちがいます）
  - 年間の授業時数を減らす（標準 1,015 時間のところを 770〜850 時間程度にする例が多い）
  - 新しい教科や「体験活動」「探究」「整える時間」などの独自の時間を設ける
  - 少人数の学級、個別の学習計画、始業時刻を遅らせるなど
  - 卒業すると**通常の学校と同じ卒業資格**が得られる（一条校）
- **対象**: 多くの公立校では「その自治体に住所があり、年間30日以上の欠席がある（または不登校傾向がある）児童生徒」が対象です。入学・転入には、説明会、見学・体験、面談などを経るのが一般的です。
- **費用**: 公立は通常の公立学校と同じで授業料はかかりません。私立は学校ごとに授業料などが必要です。

### 設置形態（4種類）

| 形態 | 内容 | 例 |
|---|---|---|
| 本校型（学校型） | 学校全体を学びの多様化学校として設置する | 八王子市立高尾山学園、岐阜市立草潤中学校 |
| 分校型 | 既存校の分校として、別の場所に設置する | 神戸市立湊翔楠中学校分校（みらいポート） |
| 分教室型 | 既存校の一部の教室（または別の建物）を分教室として設置する | 世田谷区立世田谷中学校分教室「ねいろ」 |
| コース指定型 | 主に高等学校の一部のコースを指定する | 鹿児島城西高等学校 ドリームコース |

### 国の目標

- 第4期教育振興基本計画（2023年）と「COCOLOプラン」（2023年3月）で、**すべての都道府県・政令指定都市に1校以上**設置すること、将来的には**分教室型を含めて全国300校**を設置することを目標にしています。
- 報道によると、「令和9年度（2027年度）までに全都道府県・政令市に設置」が目安とされています。

## 2. 全国の設置状況（推移）

| 時点 | 校数 | 備考 |
|---|---|---|
| 2004年度 | 2校 | 八王子市立高尾山学園、京都市立洛風中学校が最初 |
| 2021年4月 | 17校 | |
| 2023年4月 | 24校 | 公立14・私立10 |
| 2024年4月 | 35校 | 公立22・私立13 |
| 2025年4月（令和7年度） | 58校 | 公立37・私立21。19都道府県・10政令市 |
| **2026年4月（令和8年度）** | **84校** | **公立59・私立25。34都道府県**。4月に25校が新たに開校 |

2026年4月に開校した25校の内訳（文部科学省 2026年3月26日公表、報道による）

- 形態別: 本校型 9 / 分校型 6 / 分教室型 8 / コース指定型 2
- 校種別: 小学校 1 / 中学校 18 / 小中一貫 3 / 高等学校 3

2026年度の形態別の合計（にじいろ社の集計）: 本校型 32 / 分校型 12 / 分教室型 29 / コース指定型 11

### 都道府県別

- 多い順: 東京都 14、福岡県 8、神奈川県 5、岐阜県 4、兵庫県 4 など
- **未設置の13県**（2026年度時点）: 岩手、群馬、石川、福井、山梨、長野、和歌山、鳥取、広島、徳島、愛媛、佐賀、熊本
  - このうち愛媛県は宇和島市が2027年4月の開校を予定しています（[planned.md](planned.md)）。

## 3. この調査の方法と注意事項

- 調査環境のネットワーク制限により、**文部科学省のサイト（mext.go.jp）や各自治体のページを直接開くことができませんでした**。そのため、検索エンジンの結果（自治体のページ、新聞報道、教育系メディア、民間の一覧ページなど）をもとにまとめています。
- 文部科学省の公式一覧（「学びの多様化学校の設置者一覧」）がいちばん正確です。最終確認には次のページを使ってください。
  - 文部科学省「学びの多様化学校（いわゆる不登校特例校）について」: https://www.mext.go.jp/a_menu/shotou/futoukou/1387004.htm
- [schools.md](schools.md) の「確認度」の列の意味:
  - **A**: 自治体の公式ページや複数の報道で確認できたもの
  - **B**: 民間の一覧ページなど1つの資料で確認したもの
  - **C**: 検索結果の要約だけで確認したもの、または内容に食いちがいがあるもの（**要確認**）
- 指定年・開校年は資料によって「指定された年度」と「開校した年度」がまざっています。正確な年は公式資料で確認してください。
- 私立校やコース指定型の高校の「所在地」は、学校の本校所在地を一般的な情報から記入したものがあります。
- [schools.md](schools.md) には **81件（32都道府県）** を載せています。公式の84校・34都道府県に対して、**島根県・山口県の学校名は今回見つけられませんでした**。そのほか、2026年度に新しく指定された分校型・分教室型・コース指定型の一部が抜けている可能性があります。
